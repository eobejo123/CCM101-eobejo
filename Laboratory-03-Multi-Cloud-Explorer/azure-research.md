# Microsoft Azure Research

## Brief Overview
Microsoft Azure is one of the world's leading public cloud platforms, officially launched in 2010. It offers a comprehensive set of services for computing, storage, networking, databases, AI, and analytics. Azure is especially popular among organizations already using Microsoft technologies such as Windows Server, Microsoft 365, SQL Server, and Active Directory, because it integrates tightly with those existing systems.

## Global Infrastructure
Azure's infrastructure is organized into:
- **Regions** – geographical areas with one or more data centers (e.g., East US, West Europe, Southeast Asia, Japan East).
- **Availability Zones** – physically separate data centers within a region with independent power, cooling, and networking, improving fault tolerance.
- **Region Pairs** – a unique Azure feature where each region is paired with another region in the same geographic area for disaster recovery and data replication.

## Cloud Management Console
The **Azure Portal** is Microsoft's web-based interface for managing Azure resources. It provides a centralized dashboard for creating virtual machines, configuring storage accounts, building virtual networks, managing databases, and monitoring resource performance. Azure CLI and PowerShell are available for advanced automation.

## Four Core Services
1. **Azure Virtual Machines** – on-demand virtual servers in the cloud.
2. **Azure Blob Storage** – object storage for unstructured data such as files, images, and backups.
3. **Azure Virtual Network (VNet)** – secure virtual networking between resources and on-premises infrastructure.
4. **Microsoft Entra ID** (formerly Azure Active Directory) – cloud-based identity and access management with SSO and MFA support.

## Three Advantages
1. **Deep Microsoft ecosystem integration** – seamless connection with Windows Server, Microsoft 365, and Active Directory.
2. **Strong hybrid cloud support** – organizations can extend on-premises infrastructure into the cloud gradually.
3. **Enterprise-grade security and compliance** – suitable for regulated industries like finance, healthcare, and government.

## Typical Enterprise Use Cases
- Migrating on-premises Windows Server environments into a hybrid cloud setup.
- Centralizing identity management for organizations already using Active Directory.
- Hosting business applications like ERP, CRM, and HR systems.
- Running SQL Server–based enterprise databases through Azure SQL Database.
- Disaster recovery using Region Pairs.
