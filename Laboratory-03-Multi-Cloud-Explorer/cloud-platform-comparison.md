## Discussion Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services, with over 200 fully featured offerings covering nearly every category of cloud computing. Its head start since 2006 gave it time to build out the most mature and extensive service catalog of the three providers.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure best integrates with Microsoft technologies. Since Azure is developed by Microsoft, it connects natively with Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID, making it the natural choice for organizations already invested in the Microsoft ecosystem.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is strongest in AI and Kubernetes. Google created Kubernetes internally (based on its Borg system) before open-sourcing it, and GCP's Vertex AI and other machine learning tools are widely regarded as some of the most advanced in the industry.
