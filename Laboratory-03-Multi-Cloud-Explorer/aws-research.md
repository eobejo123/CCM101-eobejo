# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the world's leading public cloud computing platform, launched in 2006. It provides on-demand access to computing, storage, networking, databases, artificial intelligence, and machine learning services. AWS is the largest cloud provider by market share and is used by startups, enterprises, government agencies, and educational institutions worldwide. It follows a pay-as-you-go pricing model, allowing customers to pay only for the resources they consume.

## Global Infrastructure
AWS organizes its infrastructure into three components:
- **Regions** – geographical locations containing multiple data centers (e.g., US East N. Virginia, Europe Frankfurt, Asia Pacific Singapore).
- **Availability Zones (AZs)** – physically separate data centers within a region connected through high-speed networks, providing fault tolerance and high availability.
- **Edge Locations** – locations used by Amazon CloudFront (AWS's CDN) to cache content closer to users, reducing latency.

## Cloud Management Console
The **AWS Management Console** is a web-based graphical interface for creating, configuring, and monitoring AWS resources. Users can launch virtual machines, configure storage, manage databases, monitor resources, and view billing information without using the command line, although the AWS CLI and SDKs are available for automation.

## Four Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – virtual servers for running applications.
2. **Amazon S3 (Simple Storage Service)** – object storage for files, backups, and media.
3. **Amazon RDS (Relational Database Service)** – managed relational databases (MySQL, PostgreSQL, SQL Server, etc.).
4. **AWS IAM (Identity and Access Management)** – manages users, roles, and permissions following the Principle of Least Privilege.

## Three Advantages
1. **Broadest service portfolio** – AWS offers over 200 fully featured services, more than any competitor.
2. **Mature ecosystem** – extensive documentation, community support, and long-standing enterprise adoption since 2006.
3. **Elastic scalability** – resources like EC2 instances can scale up or down automatically based on demand.

## Typical Enterprise Use Cases
- Hosting websites and web applications with automatic scaling.
- Storing and backing up large volumes of data using S3.
- Running e-commerce platforms and financial systems requiring high availability.
- Supporting AI/ML workloads and big data analytics.
- Disaster recovery through multi-region replication.
