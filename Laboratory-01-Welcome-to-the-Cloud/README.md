# Laboratory Activity 1: Mission 1 – Welcome to the Cloud

## Mission Overview
This activity covers the fundamentals of navigating a Linux
environment, collecting system details, structuring project
files, and setting up a professional GitHub repository.

## Objectives
- Set up and access a cloud-based Linux environment through KillerCoda
- Navigate and explore the Linux operating system
- Collect key system information
- Organize files and folders using Linux commands
- Build and maintain a professional GitHub repository
- Document technical work in Markdown format

## Activities Performed
1. Started an Ubuntu environment using KillerCoda
2. Set up a new user account with administrator (sudo) access
3. Collected system details including OS, kernel, CPU, memory, and disk space
4. Organized a folder structure (Documents, Notes, Reports, Screenshots)
5. Created and documented Markdown files for the activity
6. Set up a GitHub repository to hold the Cloud Computing Portfolio

## Linux Commands Used
- `adduser`, `usermod`, `su` – for creating and managing user accounts
- `whoami`, `pwd`, `hostname` – for checking identity and location
- `lsb_release -a`, `uname -r`, `lscpu`, `free -h`, `df -h` – for viewing system information
- `mkdir`, `cd`, `ls`, `nano`, `cat` – for managing files and folders

## Skills Learned
- Fundamental Linux navigation and user account management
- Collecting and recording system information
- Setting up an organized, professional file structure
- Writing clear technical documentation in Markdown
- Creating and maintaining a GitHub repository
