## Why Disk Space Matters Before a Traffic Surge
Checking disk space before a traffic surge is critical because logs, cached files, and temporary data all grow rapidly under heavy load. If the disk fills up, the server cannot write logs or serve requests properly, turning a performance problem into a complete outage.
