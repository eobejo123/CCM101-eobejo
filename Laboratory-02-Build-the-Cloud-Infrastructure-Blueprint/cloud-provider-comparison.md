# Cloud Provider Comparison

Every major cloud provider offers roughly the same categories of
infrastructure, just branded under different product names. Below is a
side-by-side breakdown based on official AWS, Microsoft Azure, and Google
Cloud Platform documentation.

| Category | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network (VNet) | Google Virtual Private Cloud (VPC) |
| Identity & Access Management | AWS IAM | Microsoft Entra ID | Google Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
AWS takes this one, mainly because it's been around the longest — launched
back in 2006 — which gave it a huge head start in building out hundreds of
specialized services. At this point it covers almost every possible use
case, from small startups to massive enterprise workloads.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?**
Azure is the obvious pick here. If a company already runs on Windows
Server, Active Directory, SQL Server, or Microsoft 365, Azure plugs into
all of that natively — way less friction than trying to bolt Microsoft
tools onto a competitor's platform.

**3. Which platform is widely recognized for AI, ML, and Kubernetes services?**
That's Google Cloud Platform. It's worth noting Kubernetes itself actually
started as an internal Google project before going open-source, so GCP has
a natural edge there, plus a strong reputation in data analytics and
machine learning tooling like BigQuery.

**4. What similarities did you observe among the three cloud providers?**
Despite different branding, all three cover the exact same core categories
— compute, storage, networking, and identity management. They also all run
on a pay-as-you-go pricing model, offer resources on demand, and organize
their infrastructure globally through regions and availability zones.
